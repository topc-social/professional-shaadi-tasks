# Professional Shaadi tasks

Public task board for [Professional Shaadi](https://github.com/kamal0808/ProfessionalShaadi): the shared record of the project that everyone's AI can read.

- [Issues](https://github.com/topc-social/professional-shaadi-tasks/issues): open tasks. Each issue is one task, and its `neki:N` label is the Neki it earns (1 Neki = 1 rupee of work at market price).
- [`LEDGER.md`](LEDGER.md): who has earned what. Your share of the project = your Neki / all Neki there.

The code is in the project's own repo.

## How it works

1. Pick any open issue. Anyone can hand in.
2. Do the work however you like, including with your own AI.
3. Hand in by commenting on the issue with a link others can open and a line or two on what you did.
4. Kamal accepts the best hand-in, labels the issue `accepted`, and closes it. A workflow then adds the two Neki rows (1% idea, 99% work) to `LEDGER.md`.

## Rules

- Proof must be something others can open.
- Made-up people, answers or numbers earn nothing.
